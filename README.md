# Diario de Macros

App independiente de nutrición: registro de comidas con calorías, macros y micronutrientes, peso, agua, dietas personalizadas, 68 recetas y análisis de fotos de comida con IA.

- Funciona sin servidor y sin cuentas: todos los datos se guardan solo en el dispositivo.
- Instalar en iPhone: abre la web en Safari → Compartir → "Añadir a pantalla de inicio".
- Análisis de fotos: en "Perfil y objetivos" conecta tu propia clave de Google Gemini (tiene nivel gratuito), Anthropic Claude u OpenAI (o cualquier API compatible). La clave se queda en el dispositivo.
